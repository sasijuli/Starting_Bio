# Linux Basics

## Learning Goals

By the end of this module, you should be able to:

- Navigate the file system from the command line
- Create, move, copy, and delete files
- Read basic command documentation
- Understand relative and absolute paths

## Core Commands

```bash
pwd
ls
cd
mkdir
touch
cp
mv
rm
cat
less
man
```

## Key Concepts

- A directory is a folder.
- A path tells Linux where a file or directory is located.
- A relative path starts from your current location.
- An absolute path starts from the root directory, `/`.
- The `man` command opens manual pages for many Linux commands.

## Practice

1. Print your current directory with `pwd`.
2. Create a folder called `practice`.
3. Create a file called `notes.txt`.
4. Move `notes.txt` into the `practice` folder.
5. Use `man ls` to read about the `ls` command.
