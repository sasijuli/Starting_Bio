# Analyzing NAMD Results

## Goal

Understand how NAMD output can be inspected after a simulation.

## Common Workflow

1. Run the simulation with NAMD.
2. Open the structure and trajectory files in VMD.
3. Inspect the trajectory visually.
4. Measure or calculate properties of interest.
5. Record results in organized notes.

## Common Files

- `.dcd`: Load as the trajectory in VMD.
- `.log`: Read to check simulation progress and errors.
- `.coor`: Final coordinates.

## Practice

Open a simulation trajectory in VMD and describe what changes over time.
