# Large Systems And Performance

## Purpose

Work efficiently with large structures and long trajectories without exhausting memory or processing unnecessary data.

## Planned Topics

- Loading frame ranges and using stride
- Choosing compact trajectory formats
- Processing trajectories in batches
- Minimizing expensive dynamic selections
- Running VMD in text mode
- Reducing visualization complexity
- Separating interactive inspection from production analysis
- Recording software versions and performance settings

## Suggested Outcome

Design a batch workflow that tests a small frame subset before scaling to a full trajectory.
