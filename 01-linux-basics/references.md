# Linux Basics References

These references support the Linux Basics module. Prefer official manuals when checking command behavior because options may differ across systems.

## Core References

- Linux man-pages project: https://man7.org/linux/man-pages/
- Ubuntu Manpages: https://manpages.ubuntu.com/
- GNU Bash Reference Manual: https://www.gnu.org/software/bash/manual/
- GNU Coreutils Manual: https://www.gnu.org/software/coreutils/manual/

## Supplementary Learning

- The Linux Documentation Project: https://tldp.org/

## How To Use These References

- Use `man7.org` to study Linux system calls, concepts, and standard manual pages.
- Use Ubuntu Manpages when working on Ubuntu or a related distribution.
- Use the Bash manual for shell syntax, variables, expansion, pipes, and scripts.
- Use the Coreutils manual for commands such as `ls`, `cp`, `mv`, `rm`, `cat`, and `mkdir`.
