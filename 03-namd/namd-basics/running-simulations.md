# Running NAMD Simulations

## Goal

Learn the basic idea of running a NAMD simulation from the command line.

## Basic Command Pattern

```bash
namd2 simulation.conf > simulation.log
```

or:

```bash
namd3 simulation.conf > simulation.log
```

## Important Notes

- Always read the log file.
- Keep input files and output files organized.
- Do not commit large trajectory files to GitHub unless there is a specific reason.

## Practice

Run a small example simulation and identify the output files created by NAMD.
