# VMD Basics References

These references support installation, visualization, atom selections, Tcl scripting, measurements, trajectory viewing, and introductory analysis.

- Current VMD User's Guide: https://www.ks.uiuc.edu/Research/vmd/current/ug.pdf
- VMD tutorials page: https://www.ks.uiuc.edu/Training/Tutorials/
- Official Using VMD tutorial, HTML: https://www.ks.uiuc.edu/Training/Tutorials/vmd/tutorial-html/index.html
