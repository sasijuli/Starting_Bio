# Linux Basics Exercises

## Exercise 1: Create A Project Folder

Create this structure from the command line:

```text
my_project/
├── data/
├── results/
└── notes/
```

## Exercise 2: Practice File Movement

1. Create a file called `experiment_notes.txt`.
2. Move it into the `notes/` folder.
3. Copy it into the `results/` folder.
4. List the contents of each folder.

## Exercise 3: Use Manual Pages

Use `man cp` and answer:

- What does the `-r` option do?
- What does the `-i` option do?
