# NAMD

This module is divided into two learning levels:

- [NAMD Basics](namd-basics/): essential concepts for installing NAMD, understanding inputs, running a first simulation, and inspecting outputs
- [NAMD Pro](namd-pro/): advanced simulation design, specialized systems, performance, restarts, and reproducibility

## Recommended Path

1. Complete NAMD Basics in order.
2. Run and inspect a small example simulation.
3. Confirm that you understand configuration files, output logs, and restart files.
4. Continue to the advanced workflow that matches your scientific system.
