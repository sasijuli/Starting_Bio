# VMD Pro References

These references support advanced scripting, trajectory processing, specialized molecular analysis, large systems, and scientific visualization.

## Official VMD Sources

- Current VMD User's Guide: https://www.ks.uiuc.edu/Research/vmd/current/ug.pdf
- VMD plugins and extensions: https://www.ks.uiuc.edu/Research/vmd/plugins/
- VMD tutorials: https://www.ks.uiuc.edu/Training/Tutorials/
- VMD mailing list and archive: https://www.ks.uiuc.edu/Research/vmd/mailing_list/
- Tcl 8.6 command reference: https://www.tcl-lang.org/man/tcl8.6/TclCmd/contents.htm

## Trajectory Processing And Analysis

- PBCTools plugin: https://www.ks.uiuc.edu/Research/vmd/plugins/pbctools/
- Hydrogen Bonds plugin: https://www.ks.uiuc.edu/Research/vmd/plugins/hbonds/
- NAMD Energy plugin: https://www.ks.uiuc.edu/Research/vmd/plugins/namdenergy/
- VMD plugin index for RMSD, RMSF, contact maps, salt bridges, Timeline, and other analysis tools: https://www.ks.uiuc.edu/Research/vmd/plugins/

## System-Specific And Visualization Resources

- Designing Molecular Membrane Models with VMD: https://phys.libretexts.org/Courses/University_of_California_Davis/Biophysics_241%3A_Membrane_Biology/07%3A_Computational_Characterization_of_Membranes/7.04%3A_Designing_Molecular_Membranes_Models_with_VMD
- VMD Images and Movies tutorial: https://www.ks.uiuc.edu/Training/Tutorials/vmd-imgmv/imgmv/tutorial-html/node3.html
- `mkvmd_render` publication-style rendering notes: https://github.com/skblnw/mkvmd_render
