# Complete Workflow

## Learning Goals

By the end of this module, you should be able to describe a complete beginner workflow using Linux, VMD, and NAMD.

## Workflow Overview

1. Organize project folders in Linux.
2. Prepare or download a molecular structure.
3. Inspect the structure in VMD.
4. Prepare NAMD input files.
5. Run the simulation with NAMD.
6. Analyze the trajectory in VMD.
7. Document the results.

## Suggested Folder Structure

```text
example_project/
├── input/
├── scripts/
├── output/
├── analysis/
└── notes/
```

## Final Practice Project

Create a short report that includes:

- The molecular system studied
- The input files used
- The command used to run NAMD
- One image from VMD
- A short explanation of the result
