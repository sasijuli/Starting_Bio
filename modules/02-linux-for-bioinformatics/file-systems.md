# File Systems

## Key Concepts

- Linux organizes files in a hierarchical tree.
- The root directory is `/`.
- Home directories usually store user files.
- Scientific projects should be organized before data generation starts.

## Example

```bash
mkdir -p simulation_project/input simulation_project/output simulation_project/logs
```

## Good Practices

- Use descriptive folder names.
- Avoid spaces in filenames.
- Keep raw input files separate from generated output files.
- Keep notes close to the data or workflow they describe.
