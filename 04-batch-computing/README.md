# Batch Computing On Supercomputers

This module redirects to an external tutorial for learning batch job scheduling on supercomputers:

- [Getting Started with Batch Job Scheduling: Slurm Edition](https://github.com/mkandes/batch-computing/blob/main/BATCH.md)

Use this module after Linux Basics and before running long NAMD, VMD, or analysis jobs on a high-performance computing cluster.

## Learning Focus

- Understand the difference between login nodes and compute nodes
- Learn why computationally intensive work should run through a scheduler
- Recognize the role of Slurm in an HPC environment
- Practice basic scheduler commands such as `squeue` and `sinfo`
- Learn the structure of a first batch job
- Prepare for fair-share scheduling, job arrays, and job dependencies

## How To Use This Module

1. Open the external Slurm batch tutorial.
2. Read the sections on the HPC ecosystem, scheduler, and first batch job.
3. Compare the example commands with the rules for your own supercomputer.
4. Adapt job scripts only after checking your cluster documentation.
5. Return to the NAMD HPC module when you are ready to submit molecular dynamics jobs.
