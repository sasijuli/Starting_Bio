# External Link Summaries

This file stores short summaries of external links that are useful but not always part of the main tutorial flow.

## VMD

### VMD Measurements: Analyze Distances And Angles With VMD

Link: https://www.compchems.com/vmd-measurements-analyze-distances-and-angles-with-vmd/#distance-measurements-in-vmd

Short summary: A practical guide for using VMD's interactive measurement tools. It explains how to measure distances, angles, and dihedrals with keyboard pick modes, how to manage labels, and how to track measurements across trajectory frames.

Use this for: Quick GUI-based measurement practice before moving to scripted analysis.

### mkvmd_render

Link: https://github.com/skblnw/mkvmd_render

Short summary: A GitHub mini tutorial focused on making publication-style molecular images in VMD. It emphasizes Tachyon rendering, ambient occlusion, material choices, display settings, and practical image-quality improvements.

Use this for: Improving VMD screenshots and learning figure-rendering options after basic visualization is comfortable.

### Designing Molecular Membrane Models With VMD

Link: https://phys.libretexts.org/Courses/University_of_California_Davis/Biophysics_241%3A_Membrane_Biology/07%3A_Computational_Characterization_of_Membranes/7.04%3A_Designing_Molecular_Membranes_Models_with_VMD

Short summary: A membrane-modeling tutorial that introduces VMD visualization for membrane systems and discusses how CHARMM-GUI Membrane Builder can generate solvated lipid membrane models. It is useful as a domain-specific example after basic VMD loading, representation, and selection skills are learned.

Use this for: Connecting VMD visualization to membrane modeling workflows.

### Current VMD User's Guide

Link: https://www.ks.uiuc.edu/Research/vmd/current/ug.pdf

Short summary: The official VMD User's Guide for VMD 1.9.3. It covers the VMD interface, loading molecules, molecular drawing methods, coloring methods, atom selections, rendering, movies, Tcl commands, and analysis tools.

Use this for: Looking up official details when a tutorial step needs clarification.

### Official Using VMD Tutorial PDF

Link: https://www.ks.uiuc.edu/Training/Tutorials/vmd/vmd-tutorial.pdf

Short summary: The official beginner VMD tutorial. It teaches single-molecule visualization, representations, trajectories, movie making, Tcl scripting, data analysis, multiple molecules, structure comparison, MultiSeq, and running VMD on larger computing systems.

Use this for: A structured hands-on VMD practice sequence.
