# HPC And Performance

## Purpose

Run NAMD efficiently and responsibly on multicore computers and high-performance computing clusters.

## Planned Topics

- CPU and GPU execution models
- Scheduler job scripts
- Resource requests
- Parallel scaling tests
- Wall-time planning
- Checkpoint frequency
- Storage and trajectory output costs
- Reading performance information from logs
- Avoiding inefficient resource use

## Suggested Outcome

Create a benchmark table for several resource configurations before selecting settings for a long simulation.
