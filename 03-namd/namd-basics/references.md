# NAMD Basics References

These references support NAMD installation, input files, configuration files, first simulations, logs, output files, and introductory trajectory analysis.

## Official Documentation

- NAMD main page: https://www.ks.uiuc.edu/Research/namd/
- NAMD documentation archive: https://www.ks.uiuc.edu/Research/namd/documentation.html
- Current NAMD User's Guide: https://www.ks.uiuc.edu/Research/namd/current/ug.pdf
- NAMD tutorials page: https://www.ks.uiuc.edu/Training/Tutorials/

## Recommended Beginner Tutorial

- Official NAMD tutorial listing: https://www.ks.uiuc.edu/Training/Tutorials/

The official NAMD tutorial introduces basic simulations, common input and output files, protein minimization, and equilibration in water. Select the Unix/Mac or Windows instructions from the tutorial page according to your system.

## Related VMD Sources

- VMD main page: https://www.ks.uiuc.edu/Research/vmd/
- Current VMD User's Guide: https://www.ks.uiuc.edu/Research/vmd/current/ug.pdf

VMD is used to inspect NAMD structures and trajectories. Complete the VMD Basics module before attempting detailed trajectory analysis.
