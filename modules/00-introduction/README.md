# Introduction

## Learning Goals

By the end of this module, you should be able to:

- Explain why Linux is commonly used in computational biology
- Describe the roles of VMD and NAMD
- Understand how visualization and simulation tools fit into a molecular dynamics workflow

## Core Ideas

Linux provides the command-line environment used to manage files, run scientific software, and work on local computers or high-performance computing systems.

VMD is used to view molecular structures, inspect trajectories, and perform visual or script-based analysis.

NAMD is used to run molecular dynamics simulations, which model how atoms move over time.

## Suggested Workflow

1. Use Linux to organize files and run commands.
2. Use VMD to inspect molecular structures and simulation outputs.
3. Use NAMD to run molecular dynamics simulations.
4. Return to VMD to analyze the simulation trajectory.
