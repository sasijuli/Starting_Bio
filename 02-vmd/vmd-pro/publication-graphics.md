# Publication Graphics

## Purpose

Create clear, reproducible molecular figures and animations for reports, presentations, and publications.

## Planned Topics

- Choosing representations for the scientific message
- Consistent colors, materials, and backgrounds
- Camera position and clipping
- Tachyon and other rendering options
- Ambient occlusion and shadows
- Transparent surfaces
- High-resolution image export
- Reproducing a figure from a Tcl script

## Suggested Outcome

Generate one scripted, high-resolution figure whose visual settings can be recreated exactly.
