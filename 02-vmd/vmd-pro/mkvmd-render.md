# mkvmd_render

Redirect: https://github.com/skblnw/mkvmd_render

This VMD Pro module redirects to an external GitHub tutorial for publication-style molecular rendering in VMD.

Use this resource after you have a VMD scene with the representations, colors, orientation, and selections already chosen. The repository is most useful when you are ready to improve final image quality rather than decide what the figure should show.

## Learning Focus

- Improve high-resolution VMD still images
- Practice Tachyon rendering settings
- Adjust ambient occlusion, lighting, materials, and transparency
- Record rendering choices so a figure can be reproduced or revised later

## How To Use This Module

1. Open the external `mkvmd_render` GitHub repository.
2. Start with a simple VMD scene that you can render quickly.
3. Apply one rendering change at a time and compare draft images.
4. Save the VMD state or Tcl commands used to recreate the final scene.
5. Return to the local publication graphics module when writing up the final rendering settings.
