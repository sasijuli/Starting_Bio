# High-Performance Computing Basics

## Why HPC Matters

Molecular simulations can require more computing power than a regular laptop can provide. Many labs use high-performance computing clusters to run large jobs.

## Common Concepts

- **Login node**: The entry point to a cluster.
- **Compute node**: A machine where jobs run.
- **Scheduler**: Software that manages jobs.
- **Job script**: A script that requests resources and starts a program.

## Practice

- Research what job scheduler your university or lab uses.
- Write down the difference between a login node and a compute node.
