# Shell Scripting

## Purpose

Shell scripts let you save command-line steps in a file so they can be repeated.

## Example Script

```bash
#!/usr/bin/env bash

echo "Starting workflow"
pwd
ls -lh
echo "Workflow complete"
```

## Practice

1. Create a file called `run_workflow.sh`.
2. Add the example script.
3. Run it with:

```bash
bash run_workflow.sh
```
