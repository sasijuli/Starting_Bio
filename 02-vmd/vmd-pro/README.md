# VMD Pro

VMD Pro contains advanced and system-specific workflows organized as practical research questions. These pages assume that you can already load structures and trajectories, build atom selections, use the Tk Console, and understand basic Tcl syntax.

## How To Use This Section

Advanced pages are independent. Choose the workflow that matches your scientific question, document every atom selection and parameter, and test scripts on a small subset of frames before processing a complete trajectory.

## Recommended Page Structure

Each advanced page should contain:

- Scientific question
- Required files and prerequisites
- Atom selections and assumptions
- Step-by-step workflow
- Reusable Tcl script
- Validation checks
- Expected outputs
- Limitations
- External references
