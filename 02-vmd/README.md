# VMD

This module is divided into two learning levels:

- [VMD Basics](vmd-basics/): essential skills for loading, visualizing, selecting, measuring, and analyzing molecular systems
- [VMD Pro](vmd-pro/): advanced workflows for automation, specialized analyses, large trajectories, and publication-quality visualization

## Recommended Path

1. Complete the VMD Basics pages in order.
2. Practice with at least one structure and one trajectory.
3. Continue to VMD Pro only after you are comfortable with atom selections, the Tk Console, and basic Tcl commands.
4. Choose advanced pages according to the scientific system or analysis question you are studying.
