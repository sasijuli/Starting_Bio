# VMD Installation

## Goal

Install VMD and confirm that it opens correctly.

## Notes

VMD installation depends on your operating system. Always check the official VMD website for current installation instructions and licensing information.

## General Steps

1. Go to the official VMD website.
2. Register or log in if required.
3. Download the installer for your operating system.
4. Install VMD.
5. Open VMD and confirm that the main window appears.
