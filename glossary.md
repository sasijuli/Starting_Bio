# Glossary

Use this file to define important terms as the tutorial grows.

## Linux

- **Shell**: A command-line interface used to interact with the operating system.
- **Terminal**: A program that lets the user type shell commands.
- **Directory**: A folder in the file system.
- **Path**: The location of a file or directory.

## VMD

- **VMD**: Visual Molecular Dynamics, a program used to visualize and analyze molecular structures and trajectories.
- **Trajectory**: A sequence of molecular structures over time.
- **Representation**: A visual style used to display atoms, bonds, surfaces, or other molecular features.

## NAMD

- **NAMD**: A molecular dynamics program used to simulate biomolecular systems.
- **Configuration file**: A text file that tells NAMD how to run a simulation.
- **Force field**: A set of parameters and equations used to describe molecular interactions.
- **Timestep**: The small unit of simulated time advanced during a molecular dynamics simulation.
