# Linux For Bioinformatics And Simulation

## Learning Goals

By the end of this module, you should be able to:

- Organize scientific project folders
- Work with text files from the command line
- Understand why reproducible file naming matters
- Recognize the basics of working on computing clusters

## Suggested Project Layout

```text
project_name/
├── input/
├── scripts/
├── output/
├── logs/
└── notes/
```

## Core Ideas

Bioinformatics and molecular simulation projects often produce many files. A clear folder structure helps avoid confusion and makes results easier to reproduce.

Scientific workflows often use:

- Input files
- Scripts
- Output files
- Log files
- Notes or documentation

## Practice

- Create a sample project folder using the layout above.
- Write a short note explaining what each folder is for.
- Identify which files should be saved in GitHub and which files may be too large.
