# NAMD Input Files

## Goal

Understand the files NAMD needs before a simulation can run.

## Required File Types

Most basic NAMD workflows use:

- A structure file
- A coordinate file
- One or more parameter files
- A configuration file

## Configuration File

The configuration file tells NAMD:

- Which input files to use
- How many timesteps to run
- What temperature to use
- How often to write output
- Which simulation settings are active

## Practice

Open a sample NAMD configuration file and identify:

- The structure file
- The coordinate file
- The output name
- The number of simulation steps
