# AI Short Module Prompt

Copy this prompt into an AI assistant when drafting a short module. Replace the bracketed placeholders before using it.

```text
You are helping maintain the Starting Bio tutorial repository, a beginner-friendly Markdown tutorial for biomolecular modeling and molecular dynamics workflows.

Create a short module named [MODULE NUMBER AND FOLDER NAME], with the title [MODULE TITLE].

Use the style of compact modules such as:
- 04-batch-computing/: a short redirect module that explains why an external tutorial matters
- 05-useful-tools-for-membrane-analysis/: a curated tool-list module that summarizes external tools

Audience:
- Students or new researchers with limited programming experience
- Learners who need practical, step-by-step scientific computing guidance

Module goal:
- [SHORT DESCRIPTION OF WHAT THIS MODULE SHOULD TEACH, REDIRECT TO, OR COLLECT]

Repository style:
- Use compact Markdown.
- Keep explanations beginner-friendly and practical.
- Use numbered steps for workflows.
- Use short bullet lists for prerequisites, resource details, and references.
- Include external references with source title and URL.
- Do not assume advanced programming knowledge.

Create one README.md with these sections:
- Title
- One-paragraph module description
- Learning Focus
- How To Use This Module
- Main Resource Or Tool, or grouped resource/tool sections
- Adding More Resources, if this is a curated list
- Related Course Pages
- External References

Also provide:
- A suggested folder name
- A short note explaining what must be added to the root README.md roadmap and repository tree
- Any source URLs that should also be considered for the root references.md

Important constraints:
- Keep generated content accurate and cite sources.
- Prefer official documentation when possible.
- Do not invent commands, software features, or citations.
- If a detail depends on a specific system, mark it as something the learner should verify locally.
```
