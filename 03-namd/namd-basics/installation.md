# NAMD Installation

## Goal

Install NAMD and confirm that it runs from the command line.

## Notes

NAMD installation depends on the operating system and the computing environment. On clusters, NAMD may already be installed as a software module.

## General Steps

1. Check whether NAMD is already available.
2. Download NAMD from the official website if needed.
3. Follow the installation instructions for your system.
4. Run a simple test command.

## Example Check

```bash
namd2
```

or, depending on the installed version:

```bash
namd3
```
