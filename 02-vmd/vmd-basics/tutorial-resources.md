# Using External VMD Tutorials

## Goal

Learn how to use external tutorials as structured practice without losing track of what belongs in this beginner guide.

## Recommended Official Resources

The Theoretical and Computational Biophysics Group provides a central tutorial page with VMD and NAMD training material. The VMD resources include beginner tutorials, image and movie tutorials, structure checking, quantum chemistry visualization, and more specialized topics.

For this project, use external tutorials in this order:

1. **Using VMD**: basic VMD commands, molecular representations, trajectories, scripting, data analysis, multiple molecules, MultiSeq, and running VMD on larger systems.
2. **VMD Images and Movies Tutorial**: higher-quality figures, custom images, trajectory visualization, and Movie Maker workflows.
3. **VMD User's Guide**: detailed reference for interface tools, rendering methods, selection language, Tcl commands, and analysis commands.


## Supplementary VMD Links

The VMD module includes [VMD Supplementary Link Summaries](../link_summaries.md), organized by tutorial topic and learning level. Treat these links as optional enrichment rather than required material.

Use these summaries when:

- You finish a core VMD lesson and want an extra example.
- You need help deciding which external link is relevant to a specific task.
- You want to record your own notes about optional videos.

## How To Take Notes From External Tutorials

Use this pattern:

```text
Source:
Topic:
What I learned:
Commands or menu paths:
Practice result:
Questions:
```

This keeps the tutorial organized and prevents references from becoming a disconnected list of links.

## Practice

Choose one official VMD tutorial and write a short note:

- What skill does it teach?
- What files are needed?
- Which menu paths or commands are used?
- How does it connect to this module?
